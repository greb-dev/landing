# TIHO Studio Landing

Лендинг премиальной студии массажа на русском языке. Проект показывает аккуратную адаптивную верстку, визуальную композицию, секции услуг и понятные CTA для записи через WhatsApp и Telegram.

## Возможности

- Главный экран с премиальным позиционированием студии
- Секции о студии, услугах, пространстве, преимуществах, процессе визита, отзывах и FAQ
- Адаптивная навигация и мобильное меню
- CTA-кнопки для записи через мессенджеры
- Анимации появления элементов и интерактивные FAQ-блоки

## Стек

- HTML
- CSS
- JavaScript
- Google Fonts

## Запуск

Откройте `index.html` в браузере или опубликуйте проект через GitHub Pages.

## Статус

Готовый статический лендинг для демонстрации верстки и визуального дизайна.
